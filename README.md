## Princípios
1. O institucional apresenta o GEB Educação como organização educacional ampla.
2. O polo de Trindade é uma estrutura da marca, não a definição total da marca.
3. Cada modalidade conduz para o canal correto de conversão.
4. Instituição responsável/certificadora deve ser identificada quando aplicável.
5. Catálogos extensos serão estruturados por busca e filtros, não por listões.
6. O site deve ser responsivo e priorizar tráfego mobile vindo de redes sociais e WhatsApp.
